# Adding or refreshing an advisor

## Kinds of advisor

- **Role:** a type of expert (for example "Investor-friendly lender," "Luxury listing agent," "Recruiting broker"). Built from well-known public methods. No sources needed.
- **Mentor:** someone the agent learns from directly (a coach, broker, past mentor). Built from sources the agent provides: notes, recordings, transcripts, posts, course material.
- **Public figure:** a known author, coach, investor or creator. Built from their public work: books, videos, podcasts, articles, interviews, plus any sources the agent adds.

## Building great advisors

- Go deep. Use every source the agent gives, and for a Public figure, also draw on their widely known public work (mark those items "(public work)").
- The more sources, the sharper the advisor. Encourage the agent to add their favorite videos, episodes or book notes, and offer to search for well-known talks or interviews if web search is available.
- Capture what makes them distinct: their signature frameworks, the questions they always ask, the stories they always tell, their phrases.
- Label a Mentor or Public figure as a simulation in "Who they are." It never speaks for the real person.
- Quotes in "In their words" must be word for word from a source. Everything else can be retold in your own words.

## Steps: add an advisor

1. Ask: who or what kind of advisor, and what question they should own at the table.
2. Choose the Kind (Role, Mentor, Public figure).
3. For Mentor or Public figure: gather sources following `gathering-sources.md` (their favorites first, then a proposed list they approve, read each one, log ids S1, S2, ..., stop when it repeats). A Public figure can also draw on their widely known public work; offer to add more sources later with a refresh.
4. Build the brain from the sources as described in `gathering-sources.md` ("Building the brain from the sources").
5. Write the brain page following `advisor-brain-spec.md`.
6. Show the agent a short preview (their question, how they think, top beliefs) and ask "Look right?"
7. Save: add a row to Advisory Board (Advisor name, Key, Kind, Seat = their question, Status Active, or Draft if built from fewer than 5 sources, Sources = number of sources, Version 1, Last Refreshed today) and write the brain into the row's page.
8. For a Mentor or Public figure, remind the agent once: the advisor is for their own thinking, not for marketing or implying an endorsement. If you used a build folder, offer to delete it.
9. If the board now has more than 5 Active advisors, mention that meetings pick the best 5 for each topic (or the ones the agent names), and offer to bench any.

## Steps: refresh an advisor

1. Open their brain page.
2. Add new sources. Continue numbering (if the last was S6, the next is S7).
3. Update the sections the new sources change. If a position changed, write the newer view and note what it replaced, with the year.
4. Update the Sources table, the Sources count, Last Refreshed, and add 1 to Version. If a Draft now has 5 or more sources, set it to Active.
5. Tell the agent in two or three lines what changed.

## Steps: bench or bring back

- Bench: set Status to Benched. Never delete an advisor.
- Bring back: set Status to Active.
