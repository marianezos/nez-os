# Market Areas: how to save an area (Stage 6)

**Market Areas** is a database in the brain (`market_areas_ds_id`). One row per area. The row holds the quick facts; the row's page holds the full fact file.

## Row fields

| Field | From |
| --- | --- |
| Area (title) | the area name |
| Type | City, Neighborhood, Subdivision or Zip code (question 0) |
| Price Range | question 1, in their words |
| Highlights | one line on what makes it stand out, from questions 4 to 7 |
| Median Price, Avg Days on Market | only numbers they gave **with a source and date** |
| Data Source, Data As Of | where those numbers came from, and when |
| Last Updated | today's date |

Leave number fields blank rather than estimating. Never look up or guess market numbers during setup.

## Fact file (the row's page), in this order

First line: "Numbers marked [CHECK + DATE] came from the agent. Refresh them from an official source before publishing."

1. **Snapshot:** 5 bullets someone could read in 20 seconds.
2. **Homes and prices:** price range, home styles, lot sizes, HOA details.
3. **Getting around:** main roads, highway or train access, typical drive times.
4. **Things to do:** parks, trails, food, shopping, events and traditions.
5. **Insider notes:** best streets or sections for certain features, what surprises newcomers, seasonal quirks they've seen. Tell readers to check anything about flooding, drainage or other risks with the official source.
6. **What buyers, renters and investors should ask** before buying, renting or investing there.
7. **What sellers and landlords should know:** what sells fast, what inspections often flag, how to prepare. Add a short note for any other client type they work with, using only what they told you.
8. **Content ideas:** 10 post or video ideas for this area, in the agent's voice.

## Rules

- Mark every number the agent gave with **[CHECK + DATE]** using today's date.
- Before saving, remove any line that describes residents, school quality or safety as fact. Replace it with a line about the place, or drop it.
- No steering words ("perfect for families," "safe neighborhood"). Follow Compliance Guardrails.
- Use only what the agent told you. Don't add facts about the area they didn't give.
- The Local Market Expert on the Advisory Board reads these files, so a full, dated file means sharper advice.
