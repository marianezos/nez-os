# nez-leads

**Pillar:** Leads

NEZ OS Leads: lead magnets, funnels, comment-to-DM automation, ads and prospecting for real estate agents. Reads the NEZ OS brain built by the nez-os plugin.

Install the core `nez-os` plugin first: every NEZ OS plugin reads the brain it builds.

| Skill | What it does | Status |
| --- | --- | --- |
| `/nez-lead-magnet` | Finds and builds the best lead magnet for your market | Planned |
| `/nez-funnel` | Builds an opt-in funnel in GoHighLevel | Planned |
| `/nez-dm-automation` | Comment-keyword DM delivery for your lead magnets | Planned |
| `/nez-ads` | Fair Housing safe ad copy and targeting plans | Planned |
| `/nez-prospect` | Daily prospecting plans and scripts | Planned |

This plugin is added to the marketplace when its first skill is live. `references/brain-rules.md` is an exact copy of the one in `nez-os`; keep them identical.
