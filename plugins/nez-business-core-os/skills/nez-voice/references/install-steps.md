# Installing the voice skill file

Used by SKILL.md Step 7. Give these steps with the file, one at a time, and wait for them to finish each. Screens change between apps and versions, so never claim exact menu names: say "look for," and offer screenshot help.

## What they're getting

A file named for the voice, for example `marias-voice` (a zip of the folder, or the SKILL.md inside it). It's a complete skill: it works on its own, and it reads the latest guide from the Voices database in their NEZ OS brain whenever Notion is connected.

## Steps

1. **Download the file** and keep it somewhere you can find it.
2. **In Claude, look for Customize, then Skills,** and choose the option to add or upload a skill.
3. **Pick the file.** If it asks for a zip, upload the zip. If it asks for a folder, unzip it first and pick the folder named for the voice.
4. **Turn the skill on** if it asks.
5. **Test it:** type "write as [name]" or "in [name]'s voice" and ask for a short text to a past client. It should sound like the person.
6. **Screen looks different?** Send a screenshot of the Skills area and I'll adjust the steps.

## If a "save skill" card appeared in the chat

Choose Save on the card. That installs it without a file. Keep the backup file anyway.

## Updating later

When the voice is updated, you get a new file with a higher version number. Replace the installed skill with the new file (remove the old copy first if your screen asks). The Voices entry in your brain is always the latest, so the skill reads it every time, even before you reinstall.
