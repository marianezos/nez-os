# Master Profile: the blueprint

The Master Profile is the most important page in the brain. Every NEZ OS skill reads it before writing anything. This file is the exact layout: every section, every line, and what fills it. Use it to:
- know where a fact lives (save inside its section, never at the end of the page),
- rebuild a missing section or line without touching anything else,
- build the page from scratch in build mode (`workspace-build.md`).

Labels are written in bold followed by a colon (`- **Brokerage:**`). Fill the value after the colon. Never rename a label, and never delete a line or section: leave it blank instead. Current profile version: see `profile-changes.md`.

## Top of the page

1. Callout (🤖, blue): "For AI: This is the most important page in the brain. Read it before writing anything. Write in the first person as the agent, follow the Voice Library and Compliance Guardrails, and never invent facts that aren't here."
2. Callout (✏️, gray): "How to fill this in: Run /nez-setup. Your AI interviews you one question at a time and fills this page in. You can also type directly into it any time."
