# Reference dashboard templates

This folder is for reference dashboards the skill can offer as starting points after discovery. Maria's own dashboards will be added here later.

## How to add one

One file per template, named for who it's for (for example `solo-agent-new-market.md` or `team-lead.md`). Each file lists:
- Who it's for and the industry.
- The dashboards and views in order, with the purpose of each.
- The widgets on each view, with the data source and the actions.
- The brain databases it uses, with their fields.
- The connectors it needs, and what to do if one is missing.
- Notes on what worked and what the agent dropped.

## How the skill uses them

After discovery, the skill may offer a matching template as a starting point and show what it would change. A template is a suggestion, never forced, and every widget still has to pass "If you saw this, what would you do?" Never include a real person's private data in a template: use placeholders.
